# 학생 자료·과제 제출 현황 정리기 (Student Submission Tracker)

**학생 자료·과제 제출 현황 정리기**는 초·중·고등학교 담임교사 및 교과 전담교사가 매일 반복되는 학습 자료, 과제, 준비물 제출 현황을 쉽고 빠르게 관리할 수 있도록 제작된 교사용 웹 응용 프로그램입니다.

---

## 1. 프로젝트 소개

- **앱 이름**: 학생 자료·과제 제출 현황 정리기
- **개발 목적**: 매시간/매일 반복되는 과제 확인, 준비물 체크, 보완 재제출 관리를 최소한의 클릭과 키보드 조작으로 신속하고 정확하게 기록·추적합니다.
- **해결하는 문제**: 
  - 종이 수첩 관리 시 발생하는 분실 및 잦은 수정의 번거로움 해결
  - 복잡한 엑셀 프로그램의 비효율적인 조작 방식 개선
  - 전입·전출 학생 처리 시 과거 기록 누락 및 통계 오류 방지
  - 보완 재제출 대상 학생 명단 추출 및 학부모/학생 안내문 작성 시간 단축
- **주요 사용 대상**: 초·중·고 학급 담임교사 및 교과 전담교사

---

## 2. 핵심 기능

### [기본 및 학기 관리]
- **학년도·학기 관리**: 학년도 및 학기(예: 2026학년도 1학기) 단위 데이터 관리, 학기 전환 및 학기 생성
- **보관 학기 읽기 전용**: 마감된 과거 학기는 보관 처리하여 실수로 인한 데이터 수정 차단 및 안전한 조회/출력 지원

### [반 및 학생 관리]
- **반 관리**: 여러 학급/반 생성, 수정, 삭제
- **학생 명단 관리**: 단건 추가, 다중 텍스트 붙여넣기 등록, CSV 명단 일괄 불러오기
- **전입·전출 관리**: 전출 학생 비활성화(기존 제출 기록 완전 보존), 전입 학생 추가 시 기존 과제 일괄/선택 연동

### [과제 및 템플릿 관리]
- **과제 관리**: 과제 추가, 수정, 완전 삭제, 복제, 상태 변경(진행 중 / 마감 / 보관)
- **검색 및 정렬**: 과제 제목 검색, 최신순/마감임박순 정렬, 상태별 필터링
- **과제 템플릿**: 자주 활용하는 반복 과제(주간 일기, 독서록 등) 템플릿 저장/수정/삭제 및 자동 기한 규칙(+1일, +3일, +7일 등) 적용 생성

### [제출 현황 기록 및 체크]
- **4단계 제출 상태**: `미제출` / `제출` / `보완` / `완료`
- **1-Click 빠른 변경**: 한 번의 클릭 또는 키보드 단축키로 상태 즉시 반영
- **제출 체크 모드**: 연달아 학생 행을 클릭하며 '제출' 상태로 신속 변경하는 속도 최적화 모드
- **일괄 상태 변경**: 전체 또는 선택 학생의 제출 상태를 한 번에 변경
- **보완 메모**: 보완이 필요한 개별 학생에 대한 상세 사유 및 안내 메모 작성
- **Undo (되돌리기)**: 실수로 변경한 상태나 메모를 1-Click으로 즉시 복원

### [조회 및 현황 파악]
- **오늘 해야 할 일 대시보드**: 오늘 마감 과제, 미제출 상위 과제, 요약 통계 한눈에 파악
- **과제별 보기**: 과제 중심 2열 카드 / 표 가로 레이아웃 선택 조회
- **학생별 보기**: 특정 학생의 개별 과제 제출 이력 및 미제출 목록 한눈에 확인
- **학생별 누적 현황**: 반 전체 학생의 완료율, 제출/미제출/보완 건수 종합 요약
- **전체 학급 제출 매트릭스**: 행(학생)과 열(과제)을 가로/세로 고정 스크롤로 한눈에 보는 종합 가시화 그리드
- **명단 텍스트 복사**: 미제출·보완 학생 명단을 클릭 한 번으로 복사하여 알림장/메신저에 즉시 활용

### [출력 및 데이터 백업]
- **A4 현황표 인쇄**: 깔끔한 양식의 A4 프린트 출력 서식 제공
- **CSV 내보내기**: 과제별 현황 및 전체 매트릭스 현황을 UTF-8 BOM 엑셀 호환 CSV로 내보내기
- **JSON 백업 및 복원**: 전체 데이터를 안전하게 파일로 저장하고 언제든 복원

## 4. 상태 체계

| 상태명 | 코드 | 설명 |
| :--- | :--- | :--- |
| **미제출** | `unsubmitted` | 과제를 아직 제출하지 않은 기본 상태입니다. |
| **제출** | `submitted` | 학생이 과제를 제출하여 교사 검토 대기 중인 상태입니다. |
| **보완** | `supplement` | 제출했으나 수정, 내용 보완 또는 재제출이 필요한 상태입니다. |
| **완료** | `completed` | 교사의 검토 및 확인이 최종 완료된 상태입니다. |

## 5. 저장 방식

- **브라우저 LocalStorage 기반**: 본 애플리케이션은 별도의 중앙 서버 없이 사용자의 브라우저 내 `LocalStorage`에 데이터를 저장하는 클라이언트 전용 도구입니다.
- **특징 및 유의사항**:
  - 인터넷 연결 없이도 빠르고 안전하게 동작합니다.
  - 데이터는 현재 사용 중인 기기와 브라우저에만 보관되며, 다른 기기와 자동 동기화되지 않습니다.
  - 브라우저 쿠키/캐시 청소 시 데이터가 삭제될 수 있으므로, **정기적인 JSON 백업**을 권장합니다.

## 6. 데이터 안정성

구현된 자동 데이터 안정장치는 다음과 같습니다.

- **`validateAndCleanData` 로직**: 데이터 로드 및 복원 시 구조 자동 검사 및 결함 수정
- **Orphan Record 정리**: 삭제된 학생이나 삭제된 과제를 참조하는 유령 제출 기록 자동 제거
- **고유 키 보장**: `${assignmentId}_${studentId}` 조합 단일 키 구성으로 중복 제출 데이터 생성 완전 차단
- **스키마 마이그레이션 (`schemaVersion: 3`)**: 이전 버전 데이터 로드 시 누락된 필드(`termId`, `status` 등) 자동 보완
- **고엔트로피 ID 생성 (`generateUniqueId`)**: 빠른 연달아 클릭 및 일괄 작업 시 ID 충돌 방지
- **보관 학기 읽기 전용 락**: 보관된 학기 데이터의 실수 수정 차단
- **백업 파일 복원 검증**: 잘못된 형식의 JSON 파일 복원 시 기존 정상 데이터를 유실하지 않도록 사전 검증 후 반영

## 7. 데이터 구조 개요

### 데이터 관계도
```
Term (학기)
 └─ ClassGroup (반)
     └─ Student (학생)

Term / ClassGroup
 └─ Assignment (과제)
     └─ Submission (학생별 제출 기록)

AssignmentTemplate (과제 템플릿)
```

### 주요 타입 인터페이스 요약 (`/src/types/index.ts`)

```typescript
// 제출 상태
type SubmissionStatus = 'unsubmitted' | 'submitted' | 'supplement' | 'completed';

// 학기
interface Term {
  id: string;
  schoolYear: string; // 예: "2026"
  semester: string;   // 예: "2학기"
  name: string;       // 예: "2026학년도 2학기"
  status: 'active' | 'archived';
  createdAt: string;
}

// 반
interface ClassGroup {
  id: string;
  termId: string;
  name: string; // 예: "1반"
  createdAt: string;
}

// 학생
interface Student {
  id: string;
  classId: string;
  number: number;
  name: string;
  status?: 'active' | 'inactive';
  createdAt: string;
}

// 과제
interface Assignment {
  id: string;
  termId?: string;
  title: string;
  description: string;
  dueDate: string; // YYYY-MM-DD
  targetClassIds: string[];
  status?: 'active' | 'closed' | 'archived';
  createdAt: string;
}

// 제출 기록
interface Submission {
  id: string; // `${assignmentId}_${studentId}`
  assignmentId: string;
  studentId: string;
  status: SubmissionStatus;
  note: string;
  updatedAt: string;
}
```

## 9. 주요 화면 안내

1. **오늘 해야 할 일 대시보드 (`dashboard`)**: 오늘 마감 과제 및 미제출 상태 요약 통계, 주요 과제 바로가기
2. **과제별 보기 (`assignment`)**: 선택한 과제의 학생별 제출 현황 체크 및 메모 작성 (2열 카드 / 표 레이아웃)
3. **학생별 보기 (`student`)**: 개별 학생 단위 과제 제출 상태 및 미제출 항목 이력 확인
4. **학생별 누적 현황 (`student_summary`)**: 학급 전체 학생들의 누적 제출 완료율 및 수치 종합 비교
5. **전체 현황 매트릭스 (`matrix`)**: 모든 학생 × 모든 과제 제출 현황을 한눈에 확인하는 격자형 모니터링
6. **과제 및 템플릿 관리 (`assignments_manage`, `templates_manage`)**: 과제 생성/수정/복제 및 반복 과제 템플릿 관리
7. **반 및 학생 관리 (`classes_manage`)**: 학급 구성, 학생 명단 수정, CSV 불러오기, 전출/전입 관리
8. **데이터 관리 (`data_manage`)**: JSON 백업 다운로드, 백업 파일 복원, 샘플 데이터 로드 및 초기화

## 10. 키보드 단축키

과제별 보기 화면에서 학생 행에 포커스가 맞춰져 있을 때 다음 단축키를 사용할 수 있습니다.

- `1`: 포커스된 학생을 **미제출** 상태로 변경
- `2`: 포커스된 학생을 **제출** 상태로 변경
- `3`: 포커스된 학생을 **보완** 상태로 변경
- `4`: 포커스된 학생을 **완료** 상태로 변경
- `↑` / `↓`: 목록 상/하 학생으로 포커스 이동

> 💡 **참고**: 검색창, 메모 입력 모달, 이름 수정창 등 텍스트를 입력 중인 상태에서는 키보드 단축키가 자동으로 비활성화되어 입력 충돌을 방지합니다.

## 13. 인쇄 및 내보내기

- **A4 현황표 인쇄**: 과제별 보기 화면에서 `인쇄` 버튼 클릭 시 깔끔한 규격의 Printable 현황표 모달 출력 지원
- **엑셀 호환 CSV 내보내기**: 과제별 현황 및 전체 제출 매트릭스 데이터를 UTF-8 BOM 서식으로 내보내어 한글 깨짐 없이 MS Excel에서 열람 가능

## 14. 현재 버전의 제한사항

현재 버전은 **단일 브라우저 LocalStorage 기반 클라이언트 전용 버전**입니다. 따라서 다음 기능은 지원하지 않습니다.

- ❌ Firebase 또는 중앙 Cloud DB 서버 저장
- ❌ 여러 기기간 자동 실시간 동기화
- ❌ 여러 교사의 실시간 공동 편집
- ❌ 학생 전용 로그인 및 학생 직접 파일 제출 화면
- ❌ 자동 알림톡/문자 발송
